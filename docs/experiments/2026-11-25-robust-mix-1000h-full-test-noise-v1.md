# 1000h 鲁棒 LoRA 全量 test 噪声评测记录

评测于 2026-11-25 03:24:46（UTC+8）完成。基线与 LoRA 各生成 574,180 条预测，64 组条件均通过输入与预测完整性审计以及指标复算。

在 0 dB 下，LoRA 在 12 套中文、粤语及中文方言数据上的 CER 全部降低，在 4 套英文数据上的 WER 全部升高。英文 clean 的退化主要表现为替换词增加，0 dB 下则主要表现为插入词增加。按背景来源复算后，MUSAN 中确认是英语的美国政府录音子集出现了尤其明显的英文退化。

## 配置和口径

- 基线为 Qwen3-ASR-1.7B，LoRA 为 `robust_mix_1000h` 的 step 26800。训练使用 all-linear LoRA，rank 16、alpha 32、学习率 2e-5、有效 batch 32。1000 小时配方的目标配额为中文、粤语及中文方言合计 734 小时，英语 266 小时。英文配额来自 GigaSpeech 130 小时、LoquaciousSet 100 小时和 AMI 36 小时。配额是配置值，实际累计消费量不按语种报告。
- 从 16 套数据的 143,549 条源语音中隔离 4 条全零录音，剩余 143,545 条全部参与推理。每条生成统一电平后的 clean 对照，以及 20、10、0 dB 三个新增噪声版本。三个加噪条件复用同一噪声片段，仅从 v1 test 素材抽取。SNR 按整句 RMS 定义，最大编码后误差为 0.00236 dB。
- 两模型使用相同输入和归一化口径。推理采用 BF16、greedy、batch 16、`max_new_tokens=1024`，由数据集指定语种。粤语使用 `masr_zh_yue`。GigaSpeech 有 11 条参考在标准化后为空，每个条件均保留预测并跳过计分。每个模型计分 574,136 条。
- 基线结束后，LoRA 剩余任务用两个进程并行，保持同一模型和解码配置。45 秒采样中，GPU 平均利用率由单路 47.6%–49.1% 升至 92.5%，按各语料自身单路速度折算的综合吞吐约为 1.335 倍。该估计来自相邻时间窗的不同音频。

## 英文退化的误差拆解

四套英文合计 636,985 个有效参考词。以下为 LoRA 减基线，单位是百分点。各项先汇总对应错误计数，再除以相同的参考词数。

| 条件 | 替换 | 删除 | 插入 | WER 差 |
|---|---:|---:|---:|---:|
| Clean | +0.43 | +0.10 | +0.06 | +0.60 |
| 0 dB | +1.04 | −1.40 | +3.25 | +2.90 |

此前直接用原始录音推理时，这四套英文的 WER 也全部升高。AMI 在同一英文归一化口径下有所改善。由此可见，英文 clean 退化早于本轮加噪和电平处理，且随语料而异。

0 dB 的四套英文共净增 18,457 个词错误。其中 15,631 个（84.7%）来自 MUSAN speech 和 music，按音频清单中的噪声来源统计。任一模型插入至少 100 个词的样本共 24 条，贡献了 16,283 个净增词错误（88.2%）。这 24 条在两模型中同时排除后，诊断用 WER 差从 +2.90 降到约 +0.34 个百分点。正式指标仍包含这些样本。GigaSpeech 的一条 27 词参考对应 1,019 词的 LoRA 输出，展示了异常输出的量级。

## MUSAN 背景人声的语种

MUSAN 原论文确认美国政府录音全部为英语，LibriVox 部分有英语以及其他 11 种语言。按本轮 manifest 的 `trace.noise.path` 将四套英文的 `musan_speech` 样本分为 `us-gov` 与 `librivox`，再用同一语句 ID 配对 clean 对照。下表使用冻结 HM-ASR 的 WER 实现，汇总各组参考词和编辑错误。样本数是推理条数，空参考仍按原规则跳过。 [MUSAN 原论文](https://arxiv.org/pdf/1510.08484)

| 背景来源 | 样本数 | 同批 Clean WER (%) | 0 dB WER (%) | 0 dB LoRA − 基线（百分点） |
|---|---:|---:|---:|---:|
| 美国政府录音（英语） | 3,244 | 5.752 → 6.409 | 36.474 → 52.888 | +16.414 |
| LibriVox（多语种集合） | 2,156 | 5.446 → 6.119 | 49.216 → 49.233 | +0.017 |

同一 0 dB MUSAN 人声条件下，12 套中文及方言数据的 CER 均下降。对转录原文用正则 `[a-zA-Z]{2,}` 计数，输出比参考多出至少 10 个拉丁字母词串的样本从基线的 1,137 条降至 LoRA 的 6 条。这是输出内容的统计，混合音频和预测本身无法确认每个插入词来自背景说话者还是模型生成。

美国政府录音子集的结果支持同语竞争会放大英文退化。英语目标和英语背景同时存在时，英语提示无法区分两路说话。中文或方言目标加英语背景时，语种差异可能提供额外线索。两种背景来源同时存在录音场景、说话方式和音频特征差异，且 LibriVox 组没有逐条按语种拆分，因此这次比较无法估出背景语种本身的因果效应。训练配比、增强配方和解码器适配对英文 clean 的各自影响也仍未知。
